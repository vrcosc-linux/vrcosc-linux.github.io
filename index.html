VRCOSC Linux Installer

Installs, updates and launches VRCOSC inside VRChat's own Proton prefix.

Install

curl -sSL https://vrcosc-linux.github.io/install.sh | bash

Then

  • Start VRChat first, then run vrcosc or launch it from your application menu.
  • Run bash install.sh --info if anything misbehaves.

Options

Through a pipe, the flags go to bash unless you separate them with -s --. So a beta install is:

curl -sSL https://vrcosc-linux.github.io/install.sh | bash -s -- --branch beta
OptionWhat it does
-i, --infoDiagnostics: OS, Proton build, prefix, the .NET runtime VRCOSC needs versus what is installed, whether a VRChat session is joinable, and installed versus released versions. Changes nothing.
-b, --backupWrite a compressed backup of settings, profiles, packages and the prefix registries to your desktop.
-f, --forceReinstall .NET and VRCOSC even when the installed build is current or newer.
--branch live|betaRelease channel, default live. Beta installs into its own directory with a vrcosc-beta command and shares its settings with live. The installer points VRCOSC's update channel at the branch you asked for, so it will not replace itself with the other channel's build, and switches Allow Pre-Release Packages on for beta and off again on the way back to live. Changing channel also clears the package records, which belong to the other channel's SDK line — your modules are listed first, and are reinstalled from the Packages tab.
--no-patchLeave VRChat's launch.exe alone. The IPC bridge is patched in by default; without it everything works except vrchat:// navigation from VRCOSC and companion tools.
-u, --uninstallRemove the binaries, launcher and desktop entry, and restore VRChat's original launch.exe. Settings are kept.
--purgeAlso delete settings, profiles and logs for the selected branch. Use with --uninstall, or alone to drop only settings. Follows the config directory if it is a symlink, so try it with --dry-run first.
--dry-runSay what would happen and change nothing. Honoured by every mode, including --uninstall and --purge.
--no-firewallInspect the firewall and report what it finds for ports 9000, 9001 and 5353, but add no rules.
--prefix PATHUse this VRChat compatdata/438100 directory instead of searching for one.
--runtime MODEHow wine is invoked: auto (default), no-bwrap, host, container.
-h, --helpShow the options.

Environment variables

VariableEffect
VRCOSC_JOIN=0Launcher only: do not join VRChat's wine session, always run standalone.
GITHUB_TOKEN, GH_TOKENUsed for release lookups. The unauthenticated GitHub API allows 60 requests an hour per address, which shared connections exhaust.
