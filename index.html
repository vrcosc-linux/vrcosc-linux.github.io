VRCOSC Linux Installer

Installs, updates and launches VRCOSC inside VRChat's own Proton prefix.

Install

curl -sSL https://vrcosc-linux.github.io/install.sh | bash

Then

  • Start VRChat first, then run vrcosc or launch it from your application menu.
  • Run bash install.sh --info if anything misbehaves.
